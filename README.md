# 스마트 알림판 (screen2026)

교무실 TV에 띄우는 알림판입니다. 시계·날씨, 오늘/내일 학사일정, 공지, 급식, 이번 주 기도순서, 학생현황을 한 화면에 보여 주고, 아침 예배 시간(07:50~07:55)에는 찬송 가사와 성경 본문으로 바뀝니다.

- 주소: **https://paulux0808.github.io/screen2026/**
- 자료: 「2026학년도 학사일정」 구글 시트를 **읽기만** 합니다(쓰지 않습니다). 급식은 나이스, 날씨는 Open-Meteo.
- 빌드도 서버도 없습니다. GitHub에 올리면 그대로 사이트가 바뀝니다(반영까지 1~10분).

## 1. 켜면 저절로 전체화면 — 처음 한 번만 설정

웹페이지는 브라우저 보안 규칙 때문에 **사람이 누르기 전에는 스스로 전체화면이 될 수 없습니다.**
그래서 TV에 연결된 기기에서 브라우저를 처음부터 **전체화면(키오스크) 창으로 띄우는 실행 파일**을 `kiosk/` 폴더에 넣어 두었습니다. 이렇게 띄우면 주소창·탭·작업 표시줄 없이 화면 전체가 알림판이 되고, 기기를 켤 때마다 저절로 그렇게 열립니다.

### 윈도우 PC (TV에 HDMI로 연결한 컴퓨터) — 대부분 이것

1. 그 PC에 떠 있는 **알림판 화면에서 마우스를 움직이면** 맨 아래에 노란 **"설치 파일 받기 (ZIP)"** 단추가 보입니다. 누르면 `screen2026-windows.zip` 이 다운로드 폴더에 저장됩니다. 오른쪽 클릭 → **압축 풀기**.
   (그 PC에서 한 번 받으면 단추가 사라집니다. 다시 받으려면 주소 끝에 `?setup` 을 붙여 여세요. GitHub 화면의 **Code → Download ZIP** 으로 받아도 됩니다 — 그때는 `kiosk\windows` 폴더 안에 있습니다.)
2. 압축을 푼 폴더에서 `setup-board.bat` 을 **더블클릭**합니다.
   (파란 "Windows의 PC 보호" 창이 뜨면 **추가 정보 → 실행**)
3. 끝. 알림판이 바로 전체화면으로 열리고, **다음부터는 윈도우를 켜기만 하면** 저절로 전체화면으로 열립니다.

| 하고 싶은 것 | 방법 |
|---|---|
| 알림판 창 닫기 | `Alt` + `F4` |
| 지금 다시 열기 | `kiosk\windows\start-board.bat` 더블클릭 |
| 자동 실행·설정 모두 되돌리기 | `kiosk\windows\remove-board.bat` 더블클릭 |
| 이 PC의 **모든 사용자**에게 "클릭 없이 전체화면" 허용 | `kiosk\windows\allow-auto-fullscreen.reg` 더블클릭 (관리자 권한 필요) · 되돌리기는 `remove-auto-fullscreen.reg` |
| 원래 깔려 있던 **시작 프로그램을 모두 끄기** (알림판만 켜지게) | `kiosk\windows\clean-startup.bat` 더블클릭 · 되돌리기는 `restore-startup.bat` |

- Chrome이 있으면 Chrome으로, 없으면 윈도우에 기본으로 있는 Edge로 엽니다.
- 켜자마자 인터넷이 아직 안 붙었으면 30초까지 기다렸다가 엽니다. 인터넷이 끊겨 있어도 한 번이라도 열었던 기기라면 저장본으로 화면이 뜹니다.
- 무인으로 돌리려면 윈도우 **자동 로그인**과 **절전 끄기**(설정 → 시스템 → 전원)를 함께 해 두세요. 알림판이 떠 있는 동안에는 화면이 꺼지지 않게 스스로 막습니다.

#### 시작 프로그램 모두 끄기 — `clean-startup.bat`

PC를 켤 때 다른 프로그램, `.bat` 파일, `.html` 페이지 같은 것이 같이 떠서 알림판을 가리지 않도록, **로그인할 때 저절로 켜지거나 열리는 것을 모두 찾아서 끕니다.** 작업 관리자 '시작 앱'에 안 나오는 곳까지 뒤집니다.

| 찾는 곳 | 작업 관리자에 보이나 | 끄는 방법 |
|---|---|---|
| 시작 앱 (레지스트리 Run) | 보임 | '사용 안 함' 표시 |
| 시작프로그램 폴더의 `.bat` · `.html` · 바로가기 (이 사용자 · 모든 사용자) | 일부 | 보관 폴더로 옮김 |
| 작업 스케줄러: 로그인·부팅 때 도는 작업, `.bat`·`.html`·브라우저를 여는 작업 | **안 보임** | '사용 안 함' |
| 한 번 실행(RunOnce) · 정책 Run · 옛 방식 Load/Run | **안 보임** | 값을 기록한 뒤 뺌 |
| 로그인 셸(Shell · Userinit)이 다른 프로그램으로 바뀐 것 | **안 보임** | 원래 값(explorer.exe · userinit.exe)으로 |
| 브라우저(Chrome · Edge · 웨일) 정책: 시작할 때 여는 페이지 | **안 보임** | 값을 기록한 뒤 뺌 |
| 스토어 앱(Teams 등) 시작 작업 · '열려 있던 앱 다시 열기' | 일부 | 끔 |

1. 같은 폴더의 `clean-startup.bat` 더블클릭 → 관리자 확인 창에서 **예**
2. 찾은 목록이 번호와 함께 나옵니다(무엇을 실행하는지, 어디에 걸려 있는지까지).
3. **Y** = 모두 끄기 · **S** = 하나씩 고르기 · **N** = 아무것도 하지 않고 닫기 (한글 자판 상태로 ㅛ/ㄴ/ㅜ 를 눌러도 됩니다)
4. PC를 다시 시작하면 알림판만 뜹니다.

- 알림판과 Windows 보안은 건드리지 않습니다. V3·알약·NAC 같은 **보안 프로그램으로 보이는 것은 Y 를 눌러도 남기고**(S 로 골라서 끌 수는 있음), Chrome·Edge 자동 업데이트 작업도 남깁니다.
- 아무것도 지우지 않습니다. 되돌리기는 `restore-startup.bat` 한 번이면 끈 것이 모두 원래대로 돌아옵니다.
- 기록: `%LOCALAPPDATA%\screen2026\startup-changes-날짜.json` · 옮긴 파일: `%LOCALAPPDATA%\screen2026\startup-backup\날짜\`
- 그룹 정책 로그온 스크립트는 자동으로 끄지 않고 목록에 '직접 확인할 것'으로만 알려 줍니다(학교·교육청 정책일 수 있어서).

### 라즈베리파이 · 리눅스

```sh
git clone https://github.com/paulux0808/screen2026.git
cd screen2026/kiosk/linux
./setup-board.sh          # 로그인하면 알림판이 전체화면으로 열림 (+ 암호를 넣으면 자동 전체화면 정책까지)
./start-board.sh          # 지금 한 번 열기 (닫기: Alt+F4)
./remove-board.sh         # 되돌리기
```
Chromium이 없으면 먼저 `sudo apt install chromium` (라즈베리파이 OS에는 이미 들어 있습니다).

### 맥

`kiosk/mac/start-board.command` 를 더블클릭합니다(처음 한 번은 오른쪽 클릭 → 열기). 로그인할 때마다 열리게 하려면 **시스템 설정 → 일반 → 로그인 항목**에 이 파일을 넣습니다. 닫기: `Cmd` + `Q`.

### 안드로이드 TV 박스 · 태블릿 · 스마트 TV

- **Chrome**으로 주소를 열고 메뉴(⋮) → **앱 설치**(또는 홈 화면에 추가)를 누릅니다. 그 아이콘으로 열면 **처음부터 전체화면**입니다.
- 리모컨만 있으면 **확인(OK) 버튼을 한 번** 누르면 전체화면이 됩니다.
- 키오스크 앱(예: Fully Kiosk Browser)을 쓴다면 주소만 넣으면 됩니다.

### 그냥 브라우저로 주소를 열었을 때

- 위 설정(정책)을 해 둔 Chrome·Edge라면 **열자마자** 전체화면이 됩니다. 새로 고쳐도 1초쯤 뒤 다시 전체화면으로 돌아갑니다.
- 아니면 **화면 아무 데나 한 번 누르거나(클릭·터치) 아무 키나 누르면** 전체화면이 됩니다. 화면에 따로 안내를 띄우지는 않습니다.
- 누가 `Esc` 로 전체화면을 끄면 그대로 두었다가, **10분 동안 아무도 만지지 않으면** 다시 전체화면으로 돌아갑니다(정책을 해 둔 브라우저에서. 아니면 다음에 누군가 화면을 누를 때).

> 사이트 주소가 바뀌면 `kiosk/` 안 파일들 맨 위의 주소(`BOARD_URL`, `ORIGIN`, `.reg` 파일의 주소)도 같이 고쳐 주세요.

## 2. 화면 다루기

| 키 / 동작 | 하는 일 |
|---|---|
| `F` · 화면 더블클릭 | 전체화면 켜기/끄기 |
| `W` · 기도 칸의 "찬송·성경" 글자 누르기 | 아침 예배 화면 미리 보기 / 되돌리기 |
| `R` · "새로고침" 단추 | 자료를 바로 새로 받기 (전체화면이 풀리지 않음) |
| 쪽 번호(예: `1 / 2`) 누르기 | 다음 쪽 |
| 급식 칸의 "중식/석식" 누르기 | 그 끼니 보기 |

- 마우스를 움직이면 맨 아래 단추가 나타나고, 3초 동안 가만두면 마우스 커서와 단추가 숨습니다.
- 자료는 5분마다, 급식은 1시간마다, 날씨는 30분마다 새로 받습니다. 새벽 3시 30분에 한 번 페이지를 새로 엽니다.
- 맨 아래 왼쪽 점: 초록 = 정상, 노랑 = 일부 자료를 못 받음/갱신이 늦음, 빨강 = 연결 끊김(저장본을 보여 주는 중).

## 3. 설정 바꾸기 — `config.js` 만 고치면 됩니다

GitHub에서 `config.js` 를 열고 연필(✏️) 단추로 고친 뒤 **Commit changes** 를 누르면 됩니다.

| 바뀐 것 | 고칠 곳 |
|---|---|
| 구글 시트(또는 시트 주인 계정) | `sheetId` — 시트는 **링크가 있는 모든 사용자 · 뷰어**로 공유돼 있어야 합니다 |
| 시트 탭 이름 | `tabs` (띄어쓰기까지 똑같이) |
| 시정표(교시 시각) | `bells.rows` |
| 급식을 내리는 시각 | `meal.lunchEnd`, `meal.dinnerEnd` |
| 아침 예배 시간 | `worship.from`, `worship.to` |
| 학교 · 급식 | `school` |
| 날씨 위치 / 끄기 | `weather` |

시트 쪽 약속(탭 구성):
- **연중행사계획**: 날짜 · 요일 · 일정. 일정은 `[부서]내용(①②,3~4)` 처럼 적습니다. ①②③ = 학년, 숫자 = 교시, `(~20일)`·`(~3/11)` = 끝나는 날(그날까지 날마다 보임), `<자율>` = 분류.
- **공지사항**: 게시 시작일 · 게시 종료일 · 내용 — 기간 안의 공지만 보입니다.
- **기도순서**: 날짜 · 요일 · 이름 · 성경 · 찬송 / **자습감독**: 날짜 · 요일 · 이름("미운영"이라 적으면 '자습 미운영')
- **학생현황**: 학년마다 학급 · 담임 · 학생수 세 칸
- **찬송가 가사**: 장 · 가사(`(1) … (2) …`) / **성경 말씀**: 책 · 약칭 · 장 · 절 · 본문

## 5. 인터넷이 끊기면

- 받은 자료는 기기에 저장해 두므로, 끊겨도 마지막 자료를 그대로 보여 주고 상태 줄이 빨갛게 알립니다. 다시 연결되면 바로 새로 받습니다.
- 알림판 파일 자체도 기기에 보관(`sw.js`)하므로, 한 번이라도 열었던 기기는 인터넷 없이 켜도 화면이 뜹니다.

## 6. 점검 (고친 뒤 확인용)

```sh
npm i --no-save playwright && npx playwright install chromium
node tests/smoke.cjs
```
흉내 낸 시트 자료로 실제 브라우저에 열어 일정·공지·급식·기도·학생현황·아침 예배·인터넷 끊김·오프라인 보관을 확인합니다.

> ⚠️ `index.html` 을 채팅창 등에 붙여 넣었다가 다시 가져오면 `\(` · `\[` 같은 글자 쌍이 수식 기호 `$` 로 바뀌어 **일정이 통째로 안 보이는** 사고가 납니다(실제로 있었던 일). 그래서 코드는 그 글자 쌍을 쓰지 않게 짜 두었고, 위 점검이 그런 글자 쌍이 들어오면 잡아냅니다.

## 파일 구성

```
index.html            알림판 (화면 · 동작 전부)
config.js             설정 — 시트 ID · 탭 이름 · 시정표 · 급식/예배 시각
sw.js                 오프라인 보관
manifest.webmanifest  앱 설치 정보(전체화면으로 열림) · icon.svg · icon-192.png · icon-512.png
kiosk/windows/        setup-board.bat(한 번 설정) · start-board.bat(열기) · remove-board.bat(되돌리기) · *.reg(자동 전체화면 정책)
                      clean-startup.bat(시작 프로그램 모두 끄기) · restore-startup.bat(되돌리기) · clean-startup.ps1(그 내용)
kiosk/linux/          setup-board.sh · start-board.sh · remove-board.sh
kiosk/mac/            start-board.command
tests/smoke.cjs       점검
```

브라우저 저장본 이름: `board:cache:v1`(시트 자료) · `board:word:v1`(가사·본문) · `board:meal:v1`(급식) · `board:school:v1`(학교 코드). 시트 저장본에는 받아 온 시트 ID가 같이 저장되며, 지금 `sheetId` 와 다르면 쓰지 않습니다.
